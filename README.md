# Bài Tập: HTML Styles (CSS Nội Tuyến)

Bài tập thực hành sử dụng thuộc tính `style` trong HTML để định dạng màu sắc, phông chữ, cỡ chữ, căn lề và gạch chân văn bản.

## 📋 Nội dung bài tập

- Tiêu đề `<h1>`: Màu chữ xanh dương (`color: blue`).
- Đoạn văn 1: Chữ màu đỏ, in đậm (`color: red; font-weight: bold`).
- Đoạn văn 2: Chữ in nghiêng, căn giữa (`font-style: italic; text-align: center`).
- Đoạn văn 3: Cỡ chữ 20px, gạch chân (`font-size: 20px; text-decoration: underline`).

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...).
